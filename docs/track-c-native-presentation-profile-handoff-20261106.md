## Mathematical statement reached

Given two finite native Folkman two-sort objects, assume each is
equipped with a faithful finite-atom presentation recording:

* a Boolean-ring equivalence of each original native carrier with
  finite atom subsets, preserving zero, addition (symmetric difference)
  and multiplication (intersection);
* a finite matrix which recovers the **original** bilinear pairing on
  **every** pair of original native elements.

For two labelled left/right tuples of the same respective lengths, if
their complete atom profiles agree, then the *subrings generated by
these tuples in the non-unital language* are isomorphic, preserving
both ring operations, every labelled generator, and the original
cross-sort pairing on every pair of generated elements.

The new file
\`BANANA/NonPrecompact/FolkmanNativeFiniteProfileTransport.lean\`
prepares this result as
\`folkmanNativeGeneratedTwoSortIso_of_profile_eq\`.
Its \`FolkmanFinitePairingPresentation.ofCoordinates\` constructor
accepts the exact data exported by the finite-object presentation
theorem in **draft PR #305**, without importing that unverified branch.

The result does *not* identify the whole ambient finite structures,
does not construct an automorphism of a countable limit, and does not
discharge the existence of the required finite presentations. These
are important restrictions on what is being claimed.

## Adversarial mathematical checks (not independent referees)

The strongest unit trap is the empty tuple in a nonzero ambient ring.
The generated non-unital subring is {0}; replacing it by a unital
closure would be false. Both tuples may be empty, and either sort may
be the one-element zero ring.

Dropping the pairing matrix is also false: two one-atom structures
with the same nonzero membership patterns and matrices [0] and [1]
are not isomorphic as labelled two-sort pairing structures.

Nonzero membership fibres are disjoint; all generated elements are
unions of such fibres. Extra ambient atoms with the all-zero
signature are not generated and cannot affect the pairing on the
generated substructures. The native pairing is recovered by summing
the matrix entries over the selected nonzero fibres, and this
argument is unchanged under arbitrary permutations of ambient atoms.

The independently implemented finite semantic adversary in
\`scripts/check_folkman_native_presentation_profiles.py\` exercises
different ambient fibre multiplicities, arbitrary extra zero-pattern
atoms, independently permuted atom codes, the entire generated ring
operation tables, and all pairings on generated elements. A separate
local adversarial script (not yet incorporated in the GitHub branch)
ran 1,280 paired realisations, including 972 with an empty generated
sort, and 11,055 complete pairing comparisons. **These are finite
regression tests and do not certify the Lean code.**

No independent adversarial referee agents were available in this
runtime; the analysis above is not being presented as a substitute
for the required independent proof review.

## 6 November continuation: compatible embeddings and stage independence

Track C now contains
`BANANA/NonPrecompact/FolkmanNativeProfileNaturality.lean`, with
`FolkmanPresentedNativeEmbedding`. Unlike a bare assertion that an
atom embedding exists, this interface records **which** original
non-unital homomorphisms it represents, through exact partial-owner
equations on *every* native element in both sorts.

Source-level theorems (not kernel checked):

- `folkmanOwnerBiUnion_injective`: nonempty source-atom fibres make
  the induced inverse-image map on finite atom subsets injective,
  including when the source atom set is empty;
- `FolkmanPresentedNativeEmbedding.left_injective` and
  `right_injective`: faithfulness of the finite codes transfers
  this injectivity to the given original ring maps;
- `preserves_pairing`: the pairings on original native elements
  agree because the finite representations reconstruct every pairing
  value and the atom embedding preserves the source matrix;
- `tupleProfile_preserved`: the complete two-sort nonzero-pattern
  profile is natural under these *specified* embeddings;
- `folkmanTupleProfile_eq_of_commonPresentedExtension`: if two
  finite presentations of the same labelled left/right tuple embed
  compatibly into a common finite extension, their profiles coincide.

The final theorem is the exact finite-stage independence needed
before defining profiles in a countable directed Fraïssé construction.
It does not prove a directed system or the limit exists.

`Nonempty (FolkmanAtomEmbedding ...)`, omitting the equations

The proof of PR #305 already constructs `hLmap` and `hRmap`,
