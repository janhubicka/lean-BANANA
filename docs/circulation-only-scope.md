# Circulation-only archival package

This package accompanies the circulation version of *Parity obstructions to precompact Ramsey expansions*. It retains the unconditional binary Graham–Leeb–Rothschild consequence used in the one-sided BANANA Ramsey-degree classification. It includes the module-level transitive import closure of the 363 declaration references selected from the 299 manuscript validation markers. Additional declarations within those source modules may remain. No proof body or theorem statement has been changed.

The upstream `SuccessorTree/` and `RamseySpace/` modules have been copied byte-for-byte from the exact revisions used by the earlier successful strict run 46049836518 (`fc0972fda0cc25ab94ab7315f6f57b7eed9127b9`). Their original module names and namespaces are retained. The generated umbrella files import only the included modules. The fat-tree and alternative abstract Ellentuck proof routes are excluded. See [vendored-provenance.json](vendored-provenance.json) for the precise source identities and imports. The original CC0 licence of the successor-tree snapshot is included in `licenses/`; the subsequently authorised Apache-2.0 licence (licensing commit `e5ff477`) applies to the project-owned Ramsey-space code. Prior notices and permissions are retained. The repository has no external project dependency except mathlib and its pinned ecosystem.

The earlier strict run passed the mathematical source before this packaging change. This standalone package requires its own strict build, direct declaration inventory, fresh kernel replay, and named axiom audit before it can be released. The author accepted the correspondence between manuscript and formalisation on 27 November 2026, with the documented representation boundaries. The Lean formalisation was carried out by Jan Hubička using OpenAI's ChatGPT 6 and 6.2. The four manuscript authors remain unchanged. The full development history is retained separately for future versions; this package does not assert release of either upstream research library.
