# Precompact Ramsey ages with added functions

The circulation draft counts expansion isomorphism types of finite reducts and
requires a hereditary, reasonable expansion with the embedding Ramsey property.
If added functions are allowed, these conditions are compatible with infinite
copy Ramsey degrees. In fact each of the three BANANA classes has such an
expansion, even in a finite expansion language.

## Construction

Let $M$ be a countably infinite, locally finite, homogeneous structure in a
finite many-sorted language. Assume its age has strong amalgamation and the
substructure generated by the empty set has a point of each sort. The named
zeros, or the named Boolean bounds, ensure the latter condition in the BANANA
classes.

Select finite substructures of $M$, beginning with the substructure generated
by the empty set. Keep a selected finite ambient substructure $C$ containing
everything selected so far. For each selected $A$ and each finite reduct
extension $A\hookrightarrow B$, eventually service one request for its
isomorphism type over the actual $A$. A proper extension can be realised in
$M$ with its image meeting $C$ exactly in $A$. Strong amalgamation gives an
amalgam of $C$ and $B$ over $A$, and homogeneity moves the embedded copy of
$C$ back to its original position pointwise. Select the resulting copy of $B$, then select a
new ambient $C'$ strictly containing $C\cup B$ and containing the next point
of a fixed enumeration of $M$. Countably many requests can be scheduled by
assigning them distinct natural-number codes and taking the least pending code.
An extension of the same size is handled by transporting the given expansion
along the isomorphism.

Write $\mathcal F$ for the selected family. It is cofinal and closed under
binary intersections. Indeed, when $B$ is selected over $A$, its intersection
with a previously selected $D$ is $A\cap D$, and the new ambient contains all
previous members. There are finitely many selected sets of size $n$, by
induction on $n$. At most one ambient has that size. The other sets of size
$n$ come from the finitely many selected smaller sources, each of which has
finitely many reduct extensions of size $n$ up to isomorphism over the source.

Call the first selected set containing $x$ its home. Every selected set
containing $x$ contains its home. At a proper extension this follows from
$B\cap C=A$ for old points, and at an ambient step it follows by inclusion.
Each selected set is the home of at least one point. For a proper extension
there is a point outside its source, and every new ambient was chosen to have
a point outside the preceding union. Fix one representative whose home is
each selected set. Cofinality and intersection closure give a least selected
set containing any given finite subset.

## A finite expansion language

Add the following operations and relations. They can be written as a finite
list indexed by input and output sorts. A requested output in an unavailable
sort defaults to the fixed point of that sort in the substructure generated
by the empty set.

- For a point $x$, use unary operations that cycle the points of its home
  which first appeared there, in each sort, and that reach a representative of
  each nonempty sort of those points from $x$.
- At points first appearing in an attached $B$, a unary pointer reaches the
  representative of its source $A$. At points first appearing in a new
  ambient $C'$, two pointers reach the representatives of the preceding
  $C$ and $B$. The pointers for the initial home stay inside it.
- A binary operation returns the representative of the least selected set
  containing its inputs. For each input-sort pair use a version for each
  output sort, so the representative is available in its own sort.
- Use a linear order on each sort and a unary predicate on each sort marking
  the points first appearing in an ambient set. The initial home is also
  marked.

The unary operations generate the home of any point, with the initial
substructure included. Induct on the selection order. The cycles produce all
points new at this step, and the pointers generate the earlier sets which,
together with those points, make up the home. Every selected set is closed
under the operations. Conversely, in a finite closed set, successively apply
the binary operation to the representative of the least selected set reached
so far and the next point of the closed set. The unary operations then recover
that representative's home. This shows that the closed set contains its least
selected superset. The finite expanded substructures are exactly
$\mathcal F$.

Two selected sets isomorphic in the expanded language are equal. An
isomorphism identifies the points whose unary operations, together with the
initial substructure, generate the whole set. These are exactly the points
first appearing in that set. Their unary predicate identifies the ambient
case, where cardinality already identifies the set. Otherwise the first
pointers identify isomorphic attached sources. Induction gives that the
sources are the same set, and the order fixes their points. The reduct
isomorphism is therefore over the same source, for which only one request
of this type was serviced. The order now fixes every point of the selected
set.

## Consequences for the circulation statements

The actual expanded age is hereditary and has joint embedding by cofinality.
Embeddings between two finite expanded structures are unique when they
exist. This gives amalgamation and the embedding Ramsey property, with the
target itself as the Ramsey witness. It also gives homogeneity of the
expanded limit. The serviced requests give reasonableness and show that the
reducts of the expanded age are exactly the members of the original age.
Finiteness at each cardinality gives precompactness in the draft's
expansion-type sense.

The circulation expansion-degree bound and the three nonexistence claims use
restriction of a fixed expansion along every reduct embedding. A single
global convention that expansion classes in those statements add only
relations supplies this restriction, even when the reduct language already
has functions. More generally one can allow added functions whenever every
finite reduct substructure of each expanded structure is closed under them.
This is the convention needed for the existing colouring arguments.
